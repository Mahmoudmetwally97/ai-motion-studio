# 🎬 AI Motion Studio | استوديو الموشن جرافيك وصناعة الفيديو البرمجي

أداة واستوديو متكامل يعمل محلياً لإنشاء وتصدير فيديوهات موشن جرافيك برمجية بدقة 60 FPS، مع واجهة تفاعلية ومحرك تحريك وتصدير مباشر للفيديو (WebM / MP4) دون الحاجة لبرامج مونتاج معقدة.

---

## 🚀 المميزات الرئيسية

1. **واجهة تحكم تفاعلية (Web Studio):**
   * معاينة حية للموشن في الوقت الفعلي مع محاكي زمني (Timeline Scrubber) وإمكانية التنقل فريماً بفريم.
   * دعم نسب العرض المختلفة:
     * `9:16` للفيديوهات الطولية (TikTok, Instagram Reels, YouTube Shorts).
     * `16:9` للفيديوهات العريضة (YouTube, Pitch Decks).
     * `1:1` للمنشورات المربعة.
   * محرر خصائص فوري لتغيير العناوين، الألوان، الشارات، ومدد العرض مع Live Sync.

2. **قوالب موشن ذكية مبنية بالفيزياء الحركية (Spring Physics):**
   * **Kinetic Typography:** نصوص نيون سريعة تظهر كلمة بكلمة بحركات انسيابية للسوشيال ميديا.
   * **3D Tech Showcase:** بطاقة منتج زجاجية عائمة بتأثير دوران ثلاثي الأبعاد ومميزات متحركة.
   * **Data & Growth Boom:** عداد إحصائيات متصاعد رقمياً مع موجات صدمية متوهجة.
   * **AI / Dev Terminal:** سطر أوامر تفاعلي يكتب الأكواد حرفاً بحرف مع إشعارات النجاح.

3. **تصدير فوري للفيديو:**
   * تصدير بنقرة زر واحدة عبر `MediaRecorder API` المدمج مباشرة من المتصفح بجودة عالية ومعدل 60 إطاراً في الثانية.

4. **توليد برمجي للوكيل (Agent CLI Generator):**
   * يمكن للذكاء الاصطناعي إنشاء ومزامنة ملفات مواصفات الفيديو تلقائياً عبر سطر الأوامر.

---

## 🛠️ طريقة التشغيل السريعة

### 1. تشغيل الاستوديو في المتصفح:
داخل مجلد المشروع:
```bash
node server.js
```
ثم افتح المتصفح على:
👉 **`http://localhost:3000`**

### 2. التوليد البرمجي عبر سطر الأوامر (CLI):
```bash
node generate.js --title "أهلاً بكم في المستقبل" --subtitle "أقوى أداة موشن بالذكاء الاصطناعي" --template "kinetic" --aspect "9-16"
```
